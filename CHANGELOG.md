# Changelog

## 0.5.3 — 17.11.2026

Первая публичная версия.

- Отчёт о расходе лимита Claude Code по локальным логам: сколько съел каждый чат, модели и effort, холодные старты, обвязка (системный промпт, инструменты, скиллы, MCP, CLAUDE.md), агенты, «а если бы» на другой модели. Один файл, Python 3.8+, без пакетов, в интернет не ходит.
- Админка `--serve` (только 127.0.0.1): период — «Сутки», «2 дня», «Неделя», «с даты». Логи читаются один раз, смена периода занимает пару секунд. «Снять данные» перечитывает логи и оставляет выбранный период.
- «Расход по дням»: у каждого дня — день недели, доля дневного лимита и доллары по ценам API. Нажми на день — раскроются вызовы, токены (и сколько из них — чтение кэша) и чаты этого дня.
- Рядом с HTML — `.md` для нейросети: итоги, утечки, «а если бы», практики.
- Известное ограничение: Haiku 5.5 пока считается по ценам Haiku 4.5, Fable 5.2 — по ценам Fable 5.1.
